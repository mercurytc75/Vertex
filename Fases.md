Análisis del documento y división por fases
El documento describe un proyecto breve (5 días) para modelar el enfriamiento de un procesador mediante una ecuación diferencial de primer orden (Ley de enfriamiento de Newton). Se proporcionan datos concretos (T₀=80°C, Tₐ=30°C, k=0.18 min⁻¹), la EDO, la solución analítica y hasta una tabla de datos simulados. También se especifica la estructura del reporte y la rúbrica de evaluación.

Elementos clave identificados
Fenómeno físico: Enfriamiento de un procesador tras cesar una tarea exigente.

Modelo matemático: dT/dt = -k(T - Tₐ), con condición inicial T(0)=80.

Solución explícita: T(t)=30+50e^{-0.18t}.

Requerimientos del reporte: Portada, introducción, planteamiento, objetivo, marco teórico breve, modelo, solución analítica, resultados (tabla, gráfica, cálculos), discusión, conclusiones, referencias.

TICs: Uso de software para graficar (Excel, Python, GeoGebra, etc.).

Criterios de evaluación: 100 puntos, con énfasis en solución analítica (20 pts), modelo (15 pts), gráfica (10 pts), etc.
